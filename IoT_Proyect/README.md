# Sistema de Registro de Vehículos - ESCOM

Este es un sistema web para el registro de alumnos y sus vehículos en la ESCOM.

## Requisitos
* XAMPP (MySQL)
* Node.js v22+

## Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar dependencias.
3. Importar el archivo `database.sql` en phpMyAdmin.
4. Iniciar el servidor con `node app.js`.
